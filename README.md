# 🎓 Sinos-Calc - Calculadora de Graus Unisinos

Sinos-Calc é uma calculadora desenvolvida para ajudar estudantes da Unisinos a calcular médias, descobrir a nota necessária para aprovação e receber recomendações sobre substituição de graus.

## 🌐 Acesse o projeto

```txt
https://sinoscalc.netlify.app
```

---

# 📚 Como funciona o sistema de notas da Unisinos

Na Unisinos, a média final normalmente é composta por:

* **Grau A (GA)** → peso 33%
* **Grau B (GB)** → peso 67%

A média final é calculada utilizando:

```txt
Média = (GA × 0.33) + (GB × 0.67)
```

Para aprovação, o aluno precisa atingir:

```txt
Média ≥ 6.0
```
